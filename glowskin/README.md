# GlowSkin

Boutique skincare & beauté — bundles, abonnement, fiches produits détaillées.

## Structure

- `index.html` — la boutique (HTML/CSS/JS, sans dépendance)
- `assets/cart.js` — panier, codes promo, commande
- `assets/shop.js` — recherche, fiche produit, sections À propos / Contact / Avis / Newsletter

## Lancer

Ouvrir `index.html` dans le navigateur (ou « Open with Live Server » dans VS Code).

Code promo : `GLOW10`
